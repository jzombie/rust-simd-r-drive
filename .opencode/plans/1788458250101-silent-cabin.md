# Recovery Performance: Final Assessment

## Profile Data

| Metric | Value |
|--------|-------|
| User CPU | 1.29s (180ns/record for 7.1M records) |
| System CPU | 20.13s (kernel pread memory copies of 57GB) |
| I/O Wait | 43.14s (drive throughput at 1.33GB/s) |
| Wall clock | 64.56s |

## Conclusion

User-space code is already highly optimized at 180ns per record. The 20s system time is kernel-level `copy_from_user` during pread — this cannot be reduced from user space. The remaining optimizations are cosmetic.

## Remaining Change: IdentityHasher

**File:** `src/storage_engine/digest/xxh3_build_hasher.rs` + `src/storage_engine/key_indexer.rs`

Switch `KeyIndexer` from `Xxh3BuildHasher` to an `IdentityHasher` that passes `u64` keys through without re-hashing. This is a code cleanliness improvement with ≤0.2s wall-clock impact.

```rust
#[derive(Default)]
pub struct IdentityHasher(u64);

impl Hasher for IdentityHasher {
    #[inline]
    fn finish(&self) -> u64 { self.0 }

    #[inline]
    fn write(&mut self, _bytes: &[u8]) {
        unreachable!("KeyIndexer only hashes u64 keys");
    }

    #[inline]
    fn write_u64(&mut self, i: u64) {
        self.0 = i;
    }
}

pub type IdentityBuildHasher = BuildHasherDefault<IdentityHasher>;
```

Do NOT increase window size to 512MB — 64MB already saturates the I/O queue and 512MB adds allocation overhead for no gain.
